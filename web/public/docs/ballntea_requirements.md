# 볼앤티 MBTI + 에너지 매칭 테스트 요구사항 정의서

## 1. 프로젝트 개요

- **브랜드 컨셉**: “볼앤티(Ball&Tea)” 15종 티를 MBTI·에너지 페르소나에 연결해 하루의 102% 에너지를 세팅해 주는 레트로팝 감성 경험.
- **목표**  
  - 사용자가 30문항 선택형 테스트로 자신의 MBTI 4지표와 에너지 방향(외/내향, 활동/정적, Head·Heart·Gut)을 이해하도록 돕는다.  
  - 결과 화면에서 MBTI 시그니처 티 1종 + 에너지 루틴 티 2종(시간대별)을 추천하여 구매/공유를 자연스럽게 유도한다.  
  - 브랜드 가치 “전략적 기동력, Just for Today, 102% 에너지”를 반복 노출한다.
- **핵심 KPI**: 테스트 완료율 75%+, 결과 공유율 30%+, 티 상세 보기/장바구니 진입률 25%+, 99% 원문 정합성(텍스트·이미지).

### 1.1 톤앤매너 & 카피 가이드
- 레트로팝 포스터 무드 (굵은 산세리프 타이포, 크림/네이비/비비드 포인트) + 감성 카리스마.  
- 102%·Just for Today·“전원을 켜듯” 등 브랜드 표현을 CTA와 설명 곳곳에 삽입.  
- 결과 설명은 밝고 캐주얼, 존칭 유지, 과장 대신 구체적 행동 제안.  
- 사용자 메모리 요구 반영: 첫 문항 전 원-타임 팝업으로 응답 포맷(A/B 선택, 영문/국문 허용 etc.)을 안내.

### 1.2 제약 및 준수사항
- **데이터 정확도**: PDF 원문 대비 93% 이상, 검수 후 99% 목표. 추정/가상 데이터 금지, 출처 추적 가능해야 함.
- **PDF 파싱 규칙**: 줄바꿈/하이픈 재결합, 번호 보존, 괄호/영문 그대로, 복수 답안 배열화.  
- **이미지 캡처**: `assets/images/{datasetId}-{문제번호}-{순번}.png`, 필요 시 수동 스크린샷 (저장 경로 `C:/Users/darae/Pictures/Screenshots`). 캡션/표는 메타데이터 포함.  
- **배포 체계**: Git → Vercel 정식 배포, QA 통과 후만 merge.  
- **디버깅/테스트**: 모든 기능 작업 후 수동·자동 테스트 필수, 로그/이슈 트래킹 필수.

## 2. 사용자 및 시나리오

### 2.1 타깃
- 10대 후반~30대 직장인/대학생, 모바일 우선, MBTI 콘텐츠에 익숙하고 가벼운 테스트 경험을 원하는 사용자.

### 2.2 대표 페르소나
1. **“전략가 다룡”**: 아침형, ENTJ, 정보 수집과 퍼스널 브랜딩에 관심. 빠른 결과/공유 중요.  
2. **“마인드풀 예린”**: 감정형, Heart Center, 야간 공부/휴식 루틴 최적화가 목표.  
3. **“밸런스 추구 재민”**: 테스트 통해 루틴/티 추천을 받고 싶은 활동·정적 혼합형.

### 2.3 사용자 여정 (요약)
1. 랜딩 → 브랜드 소개 & 102% 카피 → “테스트 시작” 버튼.  
2. 원-타임 팝업(응답 규칙/톤 안내) → 문항 30개 연속 표시, 진행률 & 축 시각화.  
3. 제출 시 MBTI 4축 + 에너지 3축 계산 → 결과 리포트 (시그니처 티 카드, 그래프, 루틴 팁, 공유/구매 CTA).  
4. 결과 저장(API) → 선택 시 재도전 or 티 상세 이동.

## 3. 콘텐츠·데이터 명세

### 3.1 문항 구조 요약
- 총 33문항, 모든 문항 2지선다(A/B). 응답 즉시 해당 축 점수 +1. 미응답 불가.  
- **MBTI 20문항**: 4축(E/I, S/N, T/F, J/P) × 5문항.  
- **에너지 10문항**: 외향/내향 에너지 3문항, 활동/정적 3문항, Center(Head/Heart/Gut) 4문항.  
- **시간대 선호 3문항**: 아침형/저녁형 판정 전용 문항.  
- 텍스트는 헬스/피트니스 용어 없이 일상/감정/공부/관계 중심으로 유지.

### 3.2 MBTI 문항 세부
#### 외향(E)/내향(I)
1. 주말에 약속이 없다면?  
   - A: 무료하니 새로운 사람들과 어울릴 거리 탐색  
   - B: 집에서 혼자 넷플릭스·독서·휴식  
2. 파티나 큰 모임에서?  
   - A: 낯가림 없이 주도  
   - B: 아는 사람과 조용히 즐김  
3. 낯선 사람에게 먼저 말 걸기?  
   - A: 전혀 어렵지 않음  
   - B: 상대가 먼저 다가오면 응답  
4. 하루 종일 사람들과 어울린 후?  
   - A: 에너지 충전  
   - B: 기운 빠져 혼자 쉬고 싶음  
5. 친구 관계 스타일?  
   - A: 폭넓은 인맥  
   - B: 소수 친밀

#### 감각(S)/직관(N)
6. 대화 시 집중 포인트?  
   - A: 구체 사실/상황  
   - B: 숨은 의미/전체 흐름  
7. 새로 배울 때?  
   - A: 현실적 예시 먼저  
   - B: 개념·큰 그림 먼저  
8. 길 설명 방식?  
   - A: 정확한 위치/특징  
   - B: 방향/느낌 기반  
9. 기억 방식?  
   - A: 사실 그대로  
   - B: 분위기·아이디어  
10. 새로운 방식?  
   - A: 익숙한 방법 선호  
   - B: 새로운 시도 선호

#### 사고(T)/감정(F)
11. 친구가 힘들다 말할 때?  
   - A: 문제 분석·해결책  
   - B: 감정 공감·위로  
12. 중요한 결정?  
   - A: 객관·논리 우선  
   - B: 감정·사람 고려  
13. 피드백 스타일?  
   - A: 직설적 사실 전달  
   - B: 완곡·배려  
14. 듣고 싶은 칭찬?  
   - A: 논리적·유능  
   - B: 다정·배려  
15. 갈등 시?  
   - A: 옳고 그름 명확히  
   - B: 감정 상하지 않게

#### 판단(J)/인식(P)
16. 약속 시간?  
   - A: 10분 전 도착  
   - B: 5~10분 늦어도 무방  
17. 하루 일과 계획?  
   - A: 전날 계획·체크리스트  
   - B: 즉흥적으로 움직임  
18. 마감 대처?  
   - A: 훨씬 전에 완료  
   - B: 마감 직전 집중  
19. 책상/방 정리?  
   - A: 늘 정돈  
   - B: 창의적 혼돈  
20. 여행 준비?  
   - A: 일주일 전 리서치·계획  
   - B: 즉흥·전날 짐

### 3.3 에너지 문항 세부
#### 외향 에너지 / 내향 에너지
21. 금요일 밤 약속? (A: 만나면 힘남 / B: 집에서 충전)  
22. 하루 종일 혼자 있어야 한다면? (A: 몇 시간 못 버팀 / B: 혼자 시간 만끽)  
23. 처음 모임? (A: 금방 어울림 / B: 분위기 살핀 뒤 적응)

#### 활동형 / 정적형
24. 주말 보내는 방식? (A: 바쁘게 외출 / B: 휴식)  
25. 저녁 시간 활용? (A: 산책·집안일 / B: 소파 휴식)  
26. 여유 시간? (A: 새로운 장소/산책 / B: TV·낮잠)

#### 센터 (Head / Heart / Gut)
27. 중요한 결정? (Head vs Heart)  
28. 예상치 못한 문제? (Head vs Gut)  
29. 낯선 사람 만났을 때? (Heart vs Gut)  
30. 갈등 시 대응? (Heart vs Gut)

#### 시간대 선호 (아침형 / 저녁형)
31. 가장 집중 잘 되는 시간? (A: 아침~오전 / B: 오후~밤)  
32. 이상적인 일과 시작 시간? (A: 7~8시 / B: 10시 이후)  
33. 중요한 일 선호 시간대? (A: 아침 일찍 / B: 밤 늦게)

### 3.4 점수 계산 로직
1. **MBTI**: 각 축 A/B 선택 누적. 동점 시 tie-breaker 알고리즘(가중치, 추가 문항 혹은 최근 응답)을 사전 정의.  
2. **에너지 방향**  
   - 외향/내향: 문항 21~23 합산.  
   - 활동/정적: 문항 24~26 합산.  
   - 센터: 문항 27~30에서 Head/Heart/Gut 각각 카운트.  
3. **시간대 선호**  
   - 아침형/저녁형: 문항 31~33 합산. 득점 높은 쪽으로 판정.  
4. **MBTI × 에너지 × 시간대 매핑**  
   - 최종 4글자 MBTI + 시간대(아침/저녁) + 활동/정적 + 센터 조합 키 생성.  
   - 결과 JSON 예시  
     ```json
     {
       "mbti": "ENTJ",
       "energy": {"orientation": "외향", "activity": "활동형", "center": "Head"},
       "timePreference": "아침형",
       "timePreferenceScores": {"아침형": 3, "저녁형": 0}
     }
     ```
5. **그래프 데이터**: 각 축 득점을 0~5 스케일로 변환, 막대/레이더 차트에 활용.


  | 얼그레이 홍차 | Morning | “날카롭고 선명한 사고를 깨우는 리더의 향.” | ENTJ, Head, 아침형 | 결과 예시 이미지 |
  | 그린 포레스트 | AM 루틴 | “전원을 켜듯 바로 몰입 단계로 진입.” | 활동형 | 결과 예시 |
  | 캐모마일 | Evening | “과열된 사고를 부드럽게 식혀주는 안정된 저녁.” | 밸런스 추천 | 결과 예시 |

- **추천 알고리즘**

  2. 에너지 티 2종: (시간대 = 아침/오전/오후/저녁) 중 사용자의 상위 2개 활동 시간대에 맞는 티 ID 선택.

  4. 결과 JSON에 `signatureTea`, `energyTeas` 배열, `assets` 경로 기록.

### 3.6 이미지·자산 관리
- PDF에서 도표/다이어그램/포스터 이미지 추출 → `assets/images/{datasetId}-{문항번호}-{순번}.png`.  
- 이미지 다중일 경우 `-1`, `-2` 순번.  
- 캡션(예: “그림 1: ENTJ 시그니처 티”)을 메타데이터/JSON `caption` 필드에 저장.  
- 표는 가능 시 HTML Table/CSV 동시 추출 + 이미지 백업.  
- 모든 추출 내역을 검증 체크리스트(문항 수/선택지/정답/해설/이미지 존재 여부)로 자동 점검 후 수동 검수.

### 4.1 결과 화면 구성
1. **헤더**: “ENTJ 아침형 · 활동형 · HEAD Center” 등 조합 타이틀, 102% 캡션.  
2. **MBTI 섹션**: 4축 득점 그래프 + 5줄 요약 (프로그램에서 자동 생성 규칙 필요: 핵심 성향 5 bullet).  
3. **시그니처 티 카드**: 티 이미지, 카페인/향미 아이콘, 한 줄 카피, 구매 CTA.  
4. **에너지 설명**: 외향/내향, 활동/정적, 센터 설명을 한 단락으로 합성 (“당신은 내향·정적·Heart 타입…”).  
5. **에너지 티 2종**: 시간대 배지(아침/저녁 등) + 티명 + 설명.  
6. **Just for Today 메시지**: 사용자 맞춤 문장 템플릿 (`오늘의 목표를 한 줄로 정리하고...`).  
7. **저장/공유**: 결과 요약을 PNG로 변환, 워터마크 정책(사용자 직접 작성 캡처시에만 워터마크) 준수.

### 4.2 접근성 & 사용성
- 모바일 우선, 375px 기준→ 데스크톱 확장.  
- 키보드 조작, ARIA 라벨, 명도 대비 4.5:1 이상.  
- 문항 전환 시 200ms 미만, 결과 연산/렌더링 1초 내.  
- 중간 이탈 시 localStorage에 현재 진행/점수 저장, 복귀 시 이어하기 팝업.

- **컴포넌트**  
  - 진행 바: 4분할 라벨(E/I 등) + 전체 퍼센트.

  - 티 카드: 이미지, 티 배지(아침/점심/저녁), 해시태그, CTA.  
  - 그래프: 4축 막대 or 레이더, 에너지 3축 바.  
- **마이크로 인터랙션**: 문항 전환 슬라이드, 티 카드 호버 시 향미 아이콘 등장.  
- **콘텐츠 자리표시**: 문항 옆 키워드 아이콘(사회성/정보/감정/루틴)로 분류 가시화.

## 6. 기술 및 데이터 설계

- **프런트엔드**: React/Next.js (App Router) + TypeScript. 상태관리 Recoil/Zustand. Chart.js or Recharts.  
- **백엔드/서비스**:  
  - 정적 JSON (`/data/questions.json`, `/data/teas.json`) 빌드 타임 로딩.  
  - 응답 저장/AB 테스트 필요 시 Supabase/Firestore 등 실DB 도입.  
  - 이미지/CDN: `public/assets/images/...` + 이미지 맵 JSON.  
- **모듈 구조**  
  - `modules/scoring.ts`: MBTI/에너지 계산, 동점 처리, 결과 키 생성.  
  - `modules/recommendation.ts`: 티 매핑, 카피 템플릿 생성.  
  - `components/questions/QuestionCard.tsx`, `components/results/ResultHero.tsx` 등.  
- **국제화**: 기본 한국어, 향후 다국어 확장 대비 copy key 분리.  
- **측정/로그**: pageview, 완료율, CTA click 이벤트를 GA4/Amplitude에 전송.
