# Ball&Tea MBTI + 에너지 매칭 테스트

볼앤티 15종 티를 MBTI·에너지 페르소나에 연결해 하루의 102% 에너지를 세팅해 주는 레트로팝 감성 테스트입니다.

## 🌟 주요 기능

- **13문항 A/B 테스트**: MBTI 8문항 + 에너지 4문항 + 시간대 1문항
- **MBTI 16유형 분석**: 각 유형별 상세 설명과 특성
- **에너지 방향성 분석**: 외향/내향, 활동/정적, 센터(사고/감성/본능)
- **맞춤 티 추천**: 시그니처 티 1종 + AM/PM 루틴 티 2종
- **결과 URL 공유**: 결과를 URL로 저장하고 공유 가능
- **자동 저장**: 진행 중 이탈 시 이어하기 기능

## 🚀 기술 스택

- **Frontend**: Next.js 16 (App Router) + TypeScript
- **Styling**: Tailwind CSS 4
- **State**: React Hooks
- **Deployment**: Vercel

## 📦 설치 및 실행

```bash
# 의존성 설치
cd web
npm install

# 개발 서버 실행 (포트 4000)
npm run dev -- -p 4000

# 프로덕션 빌드
npm run build
npm start
```
